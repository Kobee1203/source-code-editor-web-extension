✨ Source Code Editor — IDE natif pour navigateur

Transformez votre navigateur en un environnement de développement complet propulsé par Monaco et les services VS Code :

• Ouvrez et modifiez des dossiers locaux via File System Access API ou Origin Private File System (OPFS).
• Clonez, comparez, validez et poussez des dépôts GitHub et GitLab directement depuis le navigateur.
• Lancez l’atelier dans un onglet dédié ou dans une fenêtre popup autonome capturant les raccourcis clavier.
• Personnalisez votre IDE avec des thèmes, packs d’icônes, grammaires TextMate et extraits OpenVSX.
• Synchronisez vos paramètres entre appareils tout en gardant vos jetons OAuth et PAT strictement locaux.
• Connectez en option l’hôte natif Local Companion pour un accès disque complet, Git natif et un terminal intégré.
