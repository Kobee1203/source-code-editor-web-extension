✨ Source Code Editor — IDE nativo per browser

Trasforma il tuo browser in un ambiente di sviluppo completo basato su Monaco e sui servizi di VS Code:

• Apri e modifica cartelle locali direttamente tramite File System Access API o Origin Private File System (OPFS).
• Clona, confronta, esegui commit e push di repository GitHub e GitLab direttamente dal browser.
• Avvia il workbench in una scheda dedicata o in una finestra popup indipendente.
• Personalizza il tuo IDE con temi dichiarativi OpenVSX, pacchetti di icone, grammatiche TextMate e snippet.
• Sincronizza le impostazioni tra dispositivi mantenendo i token OAuth e PAT rigorosamente locali.
• Collega opzionalmente l’host nativo Local Companion per accesso completo al disco, Git nativo e terminale.
