✨ Source Code Editor — ブラウザネイティブ IDE

Monaco と VS Code サービスを活用した高速で多機能な開発環境をブラウザ内で実現します:

• File System Access API または Origin Private File System (OPFS) でローカルフォルダを直接開いて編集。
• GitHub や GitLab のリポジトリをブラウザから直接クローン、差分比較、コミット、プッシュ。
• 専用ブラウザタブまたはショートカットを捕捉可能な独立ポップアップウィンドウで起動。
• OpenVSX の宣言型テーマ、アイコンパック、TextMate 文法、スニペットで IDE をカスタマイズ。
• OAuth や PAT トークンをローカルに安全に保持したまま、デバイス間で設定を同期。
• オプションの Local Companion ネイティブホストと連携し、OS ファイルアクセス、ネイティブ Git、ターミナルを利用可能。
