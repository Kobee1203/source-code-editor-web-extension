✨ Source Code Editor — IDE nativo en el navegador

Convierta su navegador en un entorno de desarrollo completo impulsado por Monaco y los servicios de VS Code:

• Abra y edite carpetas locales directamente mediante File System Access API u Origin Private File System (OPFS).
• Clone, compare, confirme y envíe repositorios de GitHub y GitLab directamente desde el navegador.
• Inicie el entorno en una pestaña dedicada o en una ventana emergente independiente.
• Personalice su IDE con temas declarativos de OpenVSX, paquetes de iconos, gramáticas TextMate y fragmentos.
• Sincronice su configuración entre dispositivos manteniendo las credenciales OAuth y PAT estrictamente locales.
• Conecte opcionalmente el host nativo Local Companion para acceso total al disco, Git nativo y terminal integrado.
