✨ Source Code Editor — IDE Nativo no Navegador

Transforme o seu navegador num ambiente de desenvolvimento completo com tecnologia Monaco e serviços VS Code:

• Abra e edite pastas locais diretamente via File System Access API ou Origin Private File System (OPFS).
• Clone, compare, faça commit e envie repositórios do GitHub e GitLab diretamente a partir do navegador.
• Inicie a bancada num separador dedicado ou numa janela popup independente.
• Personalize o seu IDE com temas declarativos do OpenVSX, pacotes de ícones, gramáticas TextMate e fragmentos.
• Sincronize as suas definições entre dispositivos mantendo os tokens OAuth e PAT estritamente locais.
• Ligue opcionalmente o anfitrião nativo Local Companion para acesso total ao disco, Git nativo e terminal integrado.
