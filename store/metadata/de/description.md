✨ Source Code Editor — Browser-native IDE

Verwandeln Sie Ihren Browser in eine leistungsstarke Entwicklungsumgebung auf Basis von Monaco und VS Code-Diensten:

• Öffnen und bearbeiten Sie lokale Ordner direkt über die File System Access API oder das Origin Private File System (OPFS).
• Klonen, vergleichen, committen und pushen Sie GitHub- und GitLab-Repositories direkt im Browser.
• Starten Sie die Workbench in einem eigenen Browser-Tab oder einem eigenständigen Popup-Fenster.
• Passen Sie Ihre IDE mit deklarativen OpenVSX-Designs, Icon-Paketen, TextMate-Grammatiken und Snippets an.
• Synchronisieren Sie Ihre Einstellungen geräteübergreifend, während OAuth- und PAT-Tokens lokal geschützt bleiben.
• Verbinden Sie optional den Local Companion Native Host für vollen Dateisystemzugriff, natives Git und Terminal.
