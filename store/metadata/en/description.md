✨ Source Code Editor — Browser-Native IDE

Turn your browser into a fast, full-featured development environment powered by Monaco and VS Code services:

• Open and edit local folders directly via the File System Access API or Origin Private File System (OPFS).
• Clone, branch, diff, commit, and push GitHub and GitLab repositories directly from the browser.
• Launch the workbench in a dedicated browser tab or a standalone desktop-like popup window.
• Customize your IDE with declarative OpenVSX themes, file icon packs, TextMate grammars, and snippets.
• Synchronize your editor settings across devices while keeping OAuth and PAT credentials strictly local.
• Optionally connect to the Local Companion native host for full OS file access, native Git, and terminal support.
