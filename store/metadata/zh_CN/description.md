✨ Source Code Editor — 浏览器原生 IDE

将您的浏览器打造为由 Monaco 与 VS Code 服务驱动的高效开发环境：

• 通过 File System Access API 或 Origin Private File System (OPFS) 直接打开并编辑本地文件夹。
• 直接在浏览器中克隆、对比、提交并推送 GitHub 与 GitLab 仓库。
• 支持在独立浏览器标签页或可捕获快捷键的独立弹窗中启动工作台。
• 使用 OpenVSX 声明式主题、文件图标包、TextMate 语法与代码片段个性化定制 IDE。
• 跨设备同步编辑器设置，同时将 OAuth 与 PAT 令牌严格保存在本地存储中。
• 可选连接 Local Companion 本地宿主程序，解锁完整磁盘读写、原生 Git 与集成终端支持。
