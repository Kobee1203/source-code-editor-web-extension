✨ Source Code Editor — IDE Nativo no Navegador

Transforme seu navegador em um ambiente de desenvolvimento completo com tecnologia Monaco e serviços VS Code:

• Abra e edite pastas locais diretamente via File System Access API ou Origin Private File System (OPFS).
• Clone, compare, faça commit e envie repositórios do GitHub e GitLab diretamente pelo navegador.
• Inicie a bancada em uma aba dedicada ou em uma janela popup independente.
• Personalize seu IDE com temas declarativos do OpenVSX, pacotes de ícones, gramáticas TextMate e snippets.
• Sincronize suas configurações entre dispositivos mantendo tokens OAuth e PAT estritamente locais.
• Conecte opcionalmente o host nativo Local Companion para acesso total ao disco, Git nativo e terminal integrado.
